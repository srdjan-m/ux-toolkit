# S10 — Dr. Elena Petrov, 45, certification test-lab engineer (VSTL)

**Snapshot:** Senior test engineer at an EAC-accredited Voting System Test Laboratory
(VSTL). Tests voting systems for conformance to VVSG 2.0, including the usability and
accessibility requirements (Principles 5–8), and reviews the manufacturer's technical
data package (TDP).

**Context:** Works through a test plan requirement by requirement. Every finding needs
evidence a third party can reproduce. Delays cost the manufacturer months.

**Goals:** Determine objectively whether each requirement is met; trace every claim in
the TDP to evidence; reproduce measurements.

**Knowledge:** VVSG — expert. Test methods — expert (photometers, sound-level meters,
usability test review). Product — only what the TDP and the system show her.

**Language & literacy:** English and Russian; tests every supported ballot language
structurally with native-speaker support.

**Abilities & assistive tech:** None; uses AT herself when testing (screen reader,
switches, headphones).

**Devices & modes:** The system under test in every mode (visual, enhanced visual,
audio, tactile, two-switch), measuring equipment, the TDP documents, the
manufacturer's usability test reports.

**Behaviours:** Reads requirements literally. Measures rather than judges. Flags any
ambiguity between the documentation and the system's behaviour.

**What breaks for them:**
- Documentation and system disagree (messages, steps, settings ranges).
- Settings that can't be verified: no visible current value for text size, contrast,
  speech rate, volume (7.1-K ranges and steps).
- Usability test reports not in ISO/IEC 25062 Common Industry Format, or missing
  required participant groups (8.3-A) or worker tasks (8.4-A).
- Features that work in visual mode but not in audio or two-switch mode (5.1-A).
- Contrast and size claims made in design px with no stated display (7.1-C, 7.1-G need
  measured values).
- Election-worker instructions not understandable by non-experts (7.3-O).

**Walkthrough tasks:** Verify the text-size and contrast settings against VVSG values on
the actual display; cast a full ballot in two-switch mode; match three poll-worker
messages to the TDP's documentation.

**Recruiting profile:** Not a usability-test participant — use this persona to
pre-check documentation and evidence before submitting to a VSTL. Real input: a
compliance or certification engineer reviewing the TDP.
